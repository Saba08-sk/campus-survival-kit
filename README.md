# 🎓 Campus Survival Kit

A Python based student companion designed to make student life more productive and organized.

## ✨ Features

- 🌟 Motivational quotes
- 📚 Subject-wise study tips
- 🎯 Daily productivity challenges
- ⏱️ Study session timer
- 📊 Study progress tracker
- 🔄 Interactive menu using a while loop

## 🛠️ Technologies Used

- Python
- Random module
- Time module
- Datetime module

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

   `python campus_kit.py`

## 📌 Purpose

This project was created to practise Python programming and learn Git and GitHub.
